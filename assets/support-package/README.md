# 🤝 初心者モードパッケージ — 楽天キッチン雑貨100社調査

このフォルダを Claude Code（デスクトップアプリ）で開くだけで、**初心者モード** が自動で開始されます。

サポーター（Claude）が **5フェーズ** で一緒に進めてくれます：

1. マニュアルを渡して、Plan Mode で一緒に計画を立てる
2. まず3件だけ試す（パイロット）
3. 100件本番
4. 結果をチェック（おかしい行を見つけて修正）
5. Google スプレッドシートに貼り付け

---

## 使い方（最小ステップ）

### 1. このフォルダを Claude Code で開く

Claude Code（デスクトップアプリ）を起動 → 「**フォルダを開く**」 → このフォルダを選択

### 2. 「このフォルダを信頼しますか？」が出たら「信頼する」

初めて開くフォルダだと確認ダイアログが出ます。**「信頼する（Trust）」** を押してください。
（自分でダウンロードしたフォルダなので安全です）

### 3. チャット欄に「こんにちは」と入力

それだけ。

Claude が `CLAUDE.md` を自動で読み込んで、初心者モードで返事してくれます。
最初に **「マニュアルを渡してください」** と聞かれるので、「このフォルダの `manual.md` を読んで」と返せばOKです。

---

## ⚠️ よくあるエラーと対処

### 「OAuthError: Unable to start session ... (503)」が出た

Claude Code のログイン用サーバーが一時的に混んでいるだけです。
- **30秒〜1分待ってから「こんにちは」を再送信** してください
- それでも出る場合は、Claude Code を **一度閉じて再起動** → もう一度フォルダを開く

このエラーはこのパッケージ側の問題ではないので、待てば解決します。

---

## あとは Claude の指示に従うだけ

「次は◯◯をします」と一歩ずつ案内してくれます。

詰まったら「ここ分からない」と聞けば、噛み砕いて説明してくれます。

最後に Google スプレッドシートのURLを聞かれるので、講座ページから提出用スプシURLをコピーして渡してください。
