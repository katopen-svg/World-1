# 🤖 案件探索エージェント — クラウドワークス自動応募パッケージ

このフォルダを Claude Code（デスクトップアプリ）で開くだけで、**案件探索エージェント** が自動で起動します。

エージェントが **5つのステージ** であなたの応募活動をサポート：

1. CrowdWorks で対象キーワード検索
2. 候補案件をスコアリング（S/A/B/Cランク）
3. Aランク以上の案件のみピックアップ
4. 案件ごとに最適化した提案文を生成
5. 応募フォームに自動入力（**送信ボタンは必ずあなたがクリック**）

---

## 使い方（最小ステップ）

### 1. このフォルダを Claude Code で開く

Claude Code（デスクトップアプリ）を起動 → 「**フォルダを開く**」 → このフォルダを選択

### 2. 「このフォルダを信頼しますか？」が出たら「信頼する」

初めて開くフォルダだと確認ダイアログが出ます。**「信頼する（Trust）」** を押してください。

### 3. **`profile.md` を編集**

エディタで `profile.md` を開いて、**【名前】【強み】【訴求ポイント】の3項目** をあなた自身の情報に書き換えてください。

例文の「茅森ショウ」をあなたの名前に置き換えるイメージ。10〜15分で完了します。

### 4. チャット欄に「こんにちは」と入力

それだけ。

エージェントが `CLAUDE.md` と `profile.md` を読み込んで、4つの設定を聞いてきます：

- 応募件数（おすすめ：1日3〜5件）
- 最低スコア（未指定なら75点 = Aランク以上）
- 対象キーワード追加（あれば）
- 応募前確認モード（ON / OFF）

「お任せ」と答えれば、デフォルト設定（3件 / 75点 / 確認モードON）で進めます。

---

## あとはエージェントの指示に従うだけ

各ステージで進捗を報告してくれます。

詰まったら「ここ分からない」と聞けば、噛み砕いて説明してくれます。

最後に **応募フォームが開いた状態で停止** するので、内容を確認して **「送信」ボタンをあなた自身でクリック** してください。
（誤応募防止のため、エージェントは送信ボタンを押しません）

## 含まれているファイル

| ファイル | 役割 | 編集 |

| `CLAUDE.md` | エージェントの動作定義（自動読み込み） | ⚠️ 触らない |

## ⚠️ 倫理ルール（絶対遵守）

- **1日3〜5件まで**（量産荒らし禁止）
- **質を下げない**（テンプレ丸出しNG）
- **最終送信はあなたがクリック**（誤応募防止）
- **クラウドワークス利用規約を遵守**（最新版を必ず確認）

---

## ⚠️ よくあるエラーと対処

### CAPTCHA / ログイン確認が出た
エージェントが停止して通知します。手動で対応してから「続けて」と伝えてください。

### 「OAuthError: 503」が出た
Claude Code 認証サーバーの一時的な混雑です。30秒〜1分待ってから再送信してください。

### スコアリングが厳しすぎて候補がゼロ
最低スコアを **65点（Bランク以上）** に下げて再実行。

---

## 完了したら

応募準備が完了したら、`logs/applications.csv` に履歴が残ります。  
スプシのメモ欄に「[N]件応募完了」と記録して、運営に活動報告してください。
