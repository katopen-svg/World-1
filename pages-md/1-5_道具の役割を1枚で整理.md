# 道具の役割を1枚で整理｜ステージクリアまであと一歩

> **ゴール**: 2つの道具の役割を声に出して説明できる状態。w1-1 のチェックポイント達成。

## ここまでのおさらい

w1-1 では4つのアクションを通って、こんなことを学んできました。

| アクション | 学んだこと |
|---|---|
| 1-2 | Claude Code は「**手を動かす AI 実行係**」 |
| 1-3 | スプレッドシートは「**Claude Code の出力先・納品場所**」 |
| 1-4 | フォルダは「**1案件 = 1フォルダ**」のルール |

学んだ内容を **1枚に整理** して、頭に焼き付けるのがこのアクションの目的です。

---

## 役割表で整理

まずはシンプルなテーブルで。

| 道具 | 役割（一言） | 主な使い場面 |
|---|---|---|
| 💻 **Claude Code** | AI 実行係 | リサーチ実行・データ整形・スプシ書き込み |
| 📊 **スプレッドシート** | 納品・管理場所 | 成果物の納品・案件履歴の管理 |

これだけ覚えれば9割OK。
